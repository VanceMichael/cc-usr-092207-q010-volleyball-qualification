# 女排锦标赛晋级计算

计算女排锦标赛小组排名、跨组晋级和淘汰赛签位。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括竞赛信息团队、参赛球队、裁判与技术代表、赛事公众用户。

资料所依据的领域事实如下：

- 十四支队伍分为三个规模不同的小组
- 各组前两名和成绩最好的两个第三名晋级
- 八强按小组赛战绩排签后进行固定交叉对阵

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
